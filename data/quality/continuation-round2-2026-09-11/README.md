## Comparison handling

The author badge now supports independent records for each intake track/comparison. A dataset badge requires complete registered coverage. A selected comparison requires evidence for every registered track for that comparison. Each check retains its own measured values and scientific review; evidence is never pooled to create a passing route. Correlation and same-direction agreement remain alternative routes, while effect magnitude and statistical significance remain contextual.

The build checks a reviewed artifact hash, every original source and measurement dependency, current result identities, complete registered group assignments, track inputs and analysis membership. Missing, changed or borrowed evidence stops regeneration. The independent reviewer found a missing binding to live group assignments and input paths; this was fixed and tested with reversed groups and substituted files. Values below 90% are no longer rounded into an apparent 90% in the check description.

Internal QC and author concordance remain separate badges. The detailed author verification state still distinguishes effect agreement from exact statistical reproduction. The acceptance policies, scientific configurations, input counts, normalization, model fits and published output files are preserved.

Browser review found and corrected GSE102471's stale processed-source label. It now says author results were compared, while retaining the partial statistical-reproduction state and its limitations. See the [browser checks](BROWSER_REVIEW.md).

See [validation results](VALIDATION.md) and [review findings and resolutions](REVIEW.md). Reproduction checks run from the repository root; the package script `check:validation-round2` covers the new evidence and readers. The original quality, author and intake gates remain in force.
