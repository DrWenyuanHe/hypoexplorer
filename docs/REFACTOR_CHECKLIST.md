# Refactor checklist

A standing checklist for refactoring the HypoExplorer app (`src/`). It captures the
invariants the codebase already relies on, so a change stays safe and consistent.
Outstanding follow-ups live in [`../TODOS.md`](../TODOS.md).

## Before you start

- [ ] Establish a green baseline: `pnpm test`, `pnpm run typecheck`, `pnpm run lint`,
      `pnpm run deadcode`.
- [ ] Know whether the change can alter **rendered/exported data**. If not, it must be
      provably output-preserving (see "Data-safety guardrail").

## Data-safety guardrail (do NOT touch when only refactoring UI/code)

These define the scientific data shown in the app. A presentation/refactor change must
leave them byte-for-byte unchanged:

- [ ] `public/pop_*.js`, `public/datasets/**`, `public/query/**`, and
      `public/nomenclature/**` bundles, plus the committed
      `data/nomenclature/nomenclature.tsv` — never regenerated by app work.
- [ ] Generators / ETL: `data/scripts/preprocess_multi.py` and the `scripts/*.mts`
      bundle builders (`migrate_macaque_bundles.mts`, `build_geo_datasets.mts`,
      `build_explorer_bundles_batch2.mts`, `build_query_index.mts`,
      `build_timeseries_bundles.mts`, `build_normalized_bundles.mts`,
      `build_nomenclature.mts`).
- [ ] Analysis seams that decide *values*: `src/utils/sampleValues.ts` (`valueAt`,
      `getGroupColumns`, grouped/raw readers), `src/utils/qcFlags.ts` (`isLowPower`),
      and the contrast/threshold/expression-unit **values** in `src/data/datasets.ts`.
- [ ] Verify with `git status -- public/ data/ scripts/`: nothing changed there.

## Single sources of truth (reuse, don't re-implement)

- [ ] Per-sample value reads → `valueAt` / `getGroupColumns` / `getGroupedValues` /
      `getRawSampleRows` in `src/utils/sampleValues.ts` (no positional `slice(0,3)`).
- [ ] Baseline/case arm display labels → `groupLabels(contrast)` in
      `src/utils/sampleValues.ts` (neutral `Baseline`/`Case` fallbacks — no
      hand-spelled `?? 'Normal'` / `?? 'Obese'` at a view site).
- [ ] Export sheet rows → `rawValueRows` / `leadingEdgeSummaryRows` in
      `src/utils/excelExport.ts` (preserve object **key order** — it sets XLSX columns).
- [ ] Writing an `.xlsx` → `writeWorkbook` in `src/utils/workbook.ts` (the single XLSX
      write path; no component touches `XLSX.utils` directly).
- [ ] Low-power / under-powered flag → `isLowPower` in `src/utils/qcFlags.ts`.
- [ ] Number formatting → `fmtP` / `fmtFDR` / `fmtCutoff` / `pToStar` / `fmtSigned` /
      `fmtMetaQ` in `src/utils/format.ts`. Display policy (decided 2026-08-19,
      research-backed): p and q share one rule — exponential at 2 sig figs below
      0.001, `toFixed(3)` above, `< 1e-300` underflow sentinel; only the pooled
      meta-analysis q floors (`fmtMetaQ`, `< 1e-10`). Exports keep full precision.
- [ ] Export click mechanics → `useExportAction` (busy state) / `exportFilename`
      (sanitizer) / `downloadFile` (anchor transport) in `src/utils/exportAction.ts`.
- [ ] Dialog chrome (backdrop, Escape, focus trap) → `src/common/Modal.tsx` — no
      hand-rolled dialog shells.
- [ ] Pathway-DB badge → `DbPill` in `src/common/DbPill.tsx` (owns the unknown-DB
      `?? '#888888'` guard — 6-digit, because the wash concatenates a 2-digit
      alpha and `'#888' + '22'` is a 5-digit hex the browser drops).
- [ ] Contrast resolution → `getActiveContrast` / `listContrasts` / `requireContrast`
      in `src/data/contrasts.ts`; bundle URL/global-key locators →
      `src/data/bundleLocators.ts` (the manifest itself stays in `datasets.ts`).
- [ ] Cross-dataset row shaping (direction / significance) → `geneRow` / `pathwayRow`
      in `src/data/crossDatasetRows.ts`, shared by the index and fallback paths.
- [ ] Category-scope chips on report pages → `useCategoryScope` / `FilterChip` in
      `src/crossdataset/forestReport.tsx`.
- [ ] Export buttons (disabled-when-busy + spinner wiring) → `ExportButton` in
      `src/common/ExportButton.tsx`; labels stay per-site props.
- [ ] Sortable table state/comparator (nulls last in BOTH directions) →
      `useSortedRows` in `src/common/useSortedRows.ts` (SummaryTable and the
      tracker's `filterAndSort` are deliberately separate).
- [ ] Pathway DB-filter + pager chrome → `PathwayToolbar` in
      `src/pathway-explorer/PathwayToolbar.tsx` (paging state stays in
      `usePathwayTable`; the DB-filter updater is `usePathwayView`'s in
      `src/explorer/explorerSession.ts`, wired via `onDatabaseToggle`).
- [ ] Legacy bundle-shape reads (`deByContrast ?? de`, `groupSamples` vs the
      normal/obese pair) → `src/data/rawTrack.ts` accessors; empty-defaults are
      the CALLERS', documented there.
- [ ] Reading an eager window global → `peekGlobalBundle` in
      `src/data/bundleSource.ts` (no inline `window.X` reads).
- [ ] Font stacks → `FONT_MONO` / `FONT_SANS` / `FONT_HEADING` in `src/styles/constants.ts`
      (Hanken Grotesk stacks are shared CSS variables in `public/fonts/typography.css`; keep data readouts monospace).
- [ ] Reference-page prose (Methodology/DataSources) → `src/common/prose.tsx`;
      StatisticsView's larger scale is deliberate and stays local.
- [ ] Link-chip text → `link.label` from `datasetExternalLinks`
      (`src/utils/datasetLinks.ts`) — never re-derive from `kind`.
- [ ] DE-direction colors → `UP_COLOR` / `DOWN_COLOR` in `src/styles/constants.ts`
      (DB colors, button accents, etc. are deliberately separate literals).
- [ ] Track loading → `loadTrackData` in `src/data/trackData.ts` (owns the whole load
      protocol; `loadTrack` / `popCache` are its implementation, and `bundleSource.ts`
      is the sole script-injection transport). It guarantees the "raw track never
      replaced" invariant that the popData memoization keys on. React components go
      through `useExplorerStore` (`src/data/explorerStore.ts`); cross-study columns
      and pathway report previews reuse `useCompareSetColumns`, which also tracks
      pathway-sibling settlement. Read the report's contrast with `popDataFor`
      after settlement rather than using that hook's default-contrast view.
- [ ] Arm counts (active contrast) → `contrastArmCounts` / `defaultArmCounts` in
      `src/data/contrasts.ts`; arm pills + n-varies badge → `ArmPills` /
      `ArmVariesBadge` in `src/common/StudyMetadata.tsx` (no hand-rolled pills).
- [ ] QC table rows/columns → the pure spec builders in `src/qc/qcTables.ts`
      (+ `qcVocabulary`); sortable-table chrome → `src/common/SortableTable.tsx`.
- [ ] Writing bundle files → `writeDatasetBundles` in `scripts/lib/bundleWriter.mts`
      (builders never hand-spell filenames/global keys; manifests are assertion
      inputs). Registry golden: the `datasetsRegistry.test.ts` snapshot is never
      regenerated to make a failure pass — fix the entry instead.
- [ ] Cross-dataset study selection → `useStudySelection` in
      `src/crossdataset/geneStudyScope.tsx` (catalog readiness, eligibility,
      query identity and reset coordination). Preserve explicit empty selections
      and bars' category-only display filtering; route state and report-query
      cancellation stay with their existing owners.
- [ ] Query-index freshness → `manifestFreshness` in `src/data/indexFreshness.ts`
      (declare needs; unverifiable = degrade to per-track). Offline closure:
      `pnpm exec tsx scripts/check_datasets.mts` (structural; default tracks only —
      `--all-tracks` parses every track) + `build_query_index.mts --check` (values).
- [ ] popData reads → `popDataFor(raw, dataset, contrast)` in `src/data/trackData.ts`
      (dataset and contrast are **required** — no default-dataset fallback).

## Verification

- [ ] `pnpm test` (vitest) green; add/extend tests for the behavior you changed.
- [ ] `pnpm run lint` (biome) clean. Do **not** run `biome format --write` on a whole
      file — the repo is lint-only and not formatted to biome's style; match the
      surrounding hand-formatting and keep diffs minimal.
- [ ] `pnpm run deadcode` (knip) clean — fix orphaned imports/exports.
- [ ] `pnpm run typecheck` (tsc --noEmit, both configs) clean — the type gate; the
      esbuild `build` does **not** type-check.
- [ ] `pnpm run build` succeeds.
- [ ] For visible changes, confirm in `pnpm run dev` (the preview). For export/format
      refactors, pin a golden test (values **and** column order).
