# HypoExplorer SEO tooling

The [Claude SEO toolkit](https://github.com/AgriciDaniel/claude-seo) is installed
for Codex in this project, matching GamerPrimer's and SciJournalRanking's v2.4.2
installation at commit `c167521da73bf560660b1dbb0a7650f7b37b1eb5`, with adapter
version 5. [seo-skills.lock.json](../seo-skills.lock.json) records the upstream pin
and SHA-256 hashes. The import verified GamerPrimer's complete managed file set
before copying it and regenerated the Codex skill copies from the vendored source.
It replaced an unlocked v2.2.5 copy (25 skills, `2384fdd`) that had its own
`CODEX_USAGE.md` and bundled runtime; that copy remains in Git history.

- The 26 active skills live in `.agents/skills/seo` and its `seo-*` siblings.
- The complete upstream snapshot, including references, scripts, agent prompts,
  extension sources and licenses, lives in `vendor/claude-seo/`.
- [scripts/seo_skills.py](../scripts/seo_skills.py) manages installation, updates
  and integrity checks. It retains upstream frontmatter and invocation policies.
- Private receipts, staging and recovery instructions live under the Git-ignored
  `.skill-installations/claude-seo/` directory.

The installation is project-local and supports Codex. The upstream Claude plugin
and optional extensions are retained as source; they are not registered or
connected. Global skills, Claude settings, Python packages and accounts are not
part of this installation. Third-party material retains its bundled licenses.

This tooling audits and plans; the site's own search pages, sitemap and robots
rules are generated by `scripts/lib/seoPages.mts` and documented in
[SEO.md](SEO.md).

## Use

Open a new Codex chat in this project if the skill list has not refreshed:

```text
$seo audit https://hypoexplorer.com
$seo-page analyze https://hypoexplorer.com/studies/
$seo-schema review the site's structured data
$seo-content review this page's content quality
```

Upstream `/seo ...` notation denotes workflows; select the corresponding `$seo`
skill in Codex. Use the available Codex equivalents for Claude-specific tools.
Agent prompt files are references, not registered Claude subagents or hooks.

For HypoExplorer, the technical, schema and sitemap workflows can review the
static `/studies/`, `/topics/` and `/methods/` pages, the generated sitemap and
robots rules, and how they link into the interactive hash routes. The planning
and content workflows can assess whether study pages answer researchers'
questions and explain dataset provenance and methodology clearly.

## Verify, check and update

Requires Python 3.10+ and Git. Run from the repository root:

```powershell
# Offline file-set and SHA-256 verification.
python scripts/seo_skills.py verify

# Read-only comparison with the highest stable upstream release.
python scripts/seo_skills.py check

# Install an explicitly requested update, with backups and verification.
python scripts/seo_skills.py update

# Or select the exact reviewed commit printed by check.
python scripts/seo_skills.py update --ref <full-commit-sha>

# Installer preservation and recovery tests; no network required.
python -m unittest discover -s tests/seo_skills -v
```

Each SEO skill instructs Codex to check for updates once at the start of an SEO
session, including automatic selection. Delegated sub-skills share the result.
Complete the requested SEO work with the installed version. If an update is
available, show the versions and comparison link after delivery and ask once
whether to install it for future sessions. Wait for approval before installing;
silence does not authorize an update. An explicit update request can be handled
immediately. A failed check is reported after delivery without claiming the
installation is current. There is no scheduled check.

Updates stage a fixed commit, reject managed local edits and unowned destinations,
and preserve replaced files with recovery records. Treat the vendor snapshot and
generated skill files as managed content. Reconcile deliberate changes in the
adapter and bump its version before updating; there is no force-overwrite flag.
Scoped Git attributes preserve the exact bytes used by the lock across checkouts.
The bundled CWV report template has a narrow ignore exception for Windows.

On this machine, while Codex's Windows sandbox is active, Python's directory
rename into or out of `.agents/skills` is denied even though PowerShell moves
and copies succeed. The October 23, 2026 import completed by rerunning the
installer's `apply` step with renames falling back to copy and delete. If an
update stops with `Access is denied`, inspect its receipt as described below
before retrying; nothing is promoted until a step records it.

A fresh clone already contains the active skills, vendor snapshot and lock. To
reproduce this setup in an empty project containing the wrapper scripts, import
an existing verified project installation:

```powershell
python scripts/seo_skills.py import --source-project 'C:/path/to/GamerPrimer'
```

Import is offline, leaves the source unchanged, records provenance privately and
does not copy credentials or a nested Git repository.

## Optional runtime

The Python execution runtime and Chromium are separate optional installations.
Inspect readiness without installing dependencies:

```powershell
python scripts/seo_runtime.py doctor --json
```

Exit code 3 means setup is required. When explicitly requested:

```powershell
python scripts/seo_runtime.py setup
# Omit Chromium when browser rendering is unnecessary.
python scripts/seo_runtime.py setup --skip-browser
```

Run tools through `python scripts/seo_runtime.py run <script.py> ...`. The launcher
uses upstream's managed runtime with the environment and browser stored under
ignored `.skill-installations/claude-seo-runtime/`. API integrations and credentials
need separate configuration. Avoid installing these dependencies globally.

## Recovery

Each applied import or update records its previous lock, candidate hashes,
per-path journal and `recovery.md` in a timestamped private record. Updates also
retain replaced files in that record. Inspect the receipt and actual paths after
an interruption. Preserve later edits before restoring backups in reverse order,
then restore the previous lock and verify. For a fresh installation, moving its
owned directories out of discovery rolls it back. The retired v2.2.5 copies are
in a `*-retire-legacy` record with their own hashes and recovery notes.

`.skill-installations/claude-seo/writer.lock` prevents overlapping writers and
survives failures. After inspecting the record and completing recovery, remove
only that guard before retrying:

```powershell
Remove-Item -LiteralPath '.skill-installations/claude-seo/writer.lock'
```

Tracked hashes suffice for verification in a fresh clone; private backups remain
on the machine that performed the operation. File validation does not confirm
that a running Codex chat has refreshed its skill inventory.
