# Shared data contracts

Generated by `pnpm run context:generate`. Edit the source or catalog, then regenerate.

All exported interface/type declarations in [src/types/index.ts](<../../../src/types/index.ts>). Types describe checked-in shapes; they do not validate runtime values, statistical conclusions or live storage. Imported and inherited types remain named references. Read [docs/DATASET_CONTRACT.md](<../../DATASET_CONTRACT.md>) for writer/reader rules and [CONTEXT.md](<../../../CONTEXT.md>) for domain meaning.
