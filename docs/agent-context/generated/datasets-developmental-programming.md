## mouse_hypo_maternal_hcd_gse242187

Mouse hypothalamus — maternal Western diet (bulk RNA-seq) — Mus musculus; bulk RNA-seq.

Male offspring whole hypothalamus, maternal regular diet vs maternal Western/hypercaloric diet, with both arms kept on the hypercaloric diet after weaning so the contrast isolates the maternal exposure — maternal Western diet programs hypothalamic inflammation and cardiometabolic dysfunction predominantly in males.
