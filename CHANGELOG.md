# Changelog

All notable changes to HypoExplorer are documented here.

Format: [version] - YYYY-MM-DD

## Unreleased

- **Human reference atlases in the expression survey and on the gene page.** The survey's Tissue & bulk section has a Reference atlases choice with GTEx V10 hypothalamus (257 donors, per-sample TPM), Human Protein Atlas 25 subregions, snRNA clusters and mouse and pig hypothalamus, and the Allen Human Brain Atlas microarray. Allen covers 102 hypothalamic tissue samples from six donors, one row per probe in log2. Each atlas is imported from hash-pinned release files, every value is replayed exactly, and nothing is fetched from the providers at runtime. A mouse symbol reaches the human gene of the same symbol, and the match is named. Values are never pooled across species or units, and no atlas group counts as a fed reference. On the gene page, one "Where <gene> is expressed" section sets the mouse sources (NeuroSeq populations and a reserved single-cell slot) beside a "Human hypothalamus" column: GTEx median TPM, each Allen probe's median of donor means, the top HPA subregions and the top HPA snRNA clusters, each in its own unit, with one link to the expression survey. Sources & validation and the acknowledgements credit each provider's release, licence and citation.
- **Search lists genes, the gene page holds the detail.** A gene search no longer opens an expanded gene view. A direct match leads the results as one row, followed by "Also matching" (POMCA and POMCB for POMC); every gene row summarizes how the gene changes across studies (significant datasets, tracks up and down, the strongest change, from the query index) and opens that gene's page. Rows no longer say why a gene matched. A direct pathway match still opens its enrichment summary.
- **Gene page rebuilt around a cross-study table.** The forest plot is retired. The page reads where the gene is expressed (NeuroSeq baseline expression, reserved single-cell slots), how it changes, and what changes with it (the pathways enriched where it changes, now scoped to the page's selected studies, and a reserved co-expression slot). "Differential expression across studies" groups tracks by research area, each area with its tally and folding from its header; significant tracks lead, and "Show all" adds every measured track. Each row states direction in words: the comparison's first group in bold and the change as a fold of that group against the second ("4.1× lower in Stat3 KO"), with log2FC, q and a bar on one shared axis. The study cell names the population, species, preparation and GEO accession. The change opens the existing expression preview, rows keep Info, Open and Compare (now the row's own population), and the study filters sit inside the card. Compare as bars and Share analysis are unchanged.
- **Pathways card as a condition matrix.** "Pathways changing in these conditions" on the gene page draws one column per condition the gene is followed into, grouped by whether the gene went down or up there and headed by the comparison's first group and the gene's log2FC, and one row per pathway, with the NES in each condition where the pathway is enriched (red above 0, blue below, darker for larger |NES|). Conditions without a pathway analysis keep a marked column. Each row ends with its recurrence and how much more often than usual; the ranking explanation moves behind "How is this ranked?". The condition list and seven-column table are retired; ranking and data are unchanged.
- The home page tagline reads "Where a gene is expressed in the hypothalamus, and how it changes across N public studies"; the page's crawlable heading matches.

- **Compare shows a population that failed to load.** A population whose data cannot be read now says so and offers Retry, instead of showing "Loading…" forever; the other populations stay usable and Export waits until every selected population has loaded.
- **Every download says what it is.** Pathway, leading-edge, Compare, compare-set, circadian and local exports now carry the Metadata record gene exports already had (dataset, track, contrast, release, retained evidence and export settings), and their filenames name the dataset, track and contrast, so exports of different contrasts never save over each other. The circadian workbook's Settings sheet is replaced by that Metadata sheet with the same settings; local imports state that they have no release, evidence or licence. Gene export content is unchanged apart from an added export-kind field.
- **One gene picker.** The Compare tab and the compare set use the Gene Explorer's picker: search, Load list and Save list, a count, Clear all, and the "now X" note on genes stored under a retired symbol, read in each study's own nomenclature (an all-mouse compare set resolves aliases through MGI; mixed species stay unscoped).
- **Explorer navigation follows one set of rules.** The home page's Quality control and Sources links open those tabs even when the explorer was last left in Compare, where Compare used to stay on screen. A Compare link (`#/dataset/<id>/compare`) reopens Compare instead of the default population, and a single-population study's Compare link opens that population. Leaving Compare returns to the population and tab it was entered from; before, it always opened the default population. Opening a study from the tracker while its explorer was in Compare shows the study. Clicking the current population in a Quality Control table opens its Gene Explorer without clearing the selected genes.
- **Unified gene and pathway search.** The home page box has no Gene/Pathway switch: one search suggests genes and pathways in two groups and opens a results page (`#/search/<query>`) with All, Genes and Pathways tabs. Genes match by symbol, by authority gene name and selected aliases from a generated dictionary (`public/nomenclature/names.js`, built from the committed nomenclature table by `npm run build:search-names`), and by a short curated list of common names, so "oxytocin" opens OXT and "orexin" opens HCRT; every redirect says why it matched. Pathway names match word by word against readable titles, so "insulin" lists the insulin gene and the insulin secretion and signaling pathways. The page opens on its best match: for a gene, where it changes across studies (log2FC, p and q per track from the query index, never the full per-track download), a NeuroSeq baseline-expression preview, and the pathways enriched in the conditions where it changes, and reserved slots for mouse and human single-cell atlases and co-expression; for a pathway, its enrichment summary. The full gene and pathway reports, with their study filters, stay one click away and in the nav.
- **Gene portal: pathways changing where the gene changes.** On a gene's search page, a card follows the gene to the tracks where it is significant (FDR < 0.05; the 12 most significant when there are more) and lists the pathways enriched there (padj < 0.05), the ones most specific to those conditions first. Each pathway's recurrence among the followed conditions is set against its base rate across all pathway-capable tracks (a one-sided hypergeometric tail, used for ordering only), so sets enriched almost everywhere, such as KEGG ribosome (104 of 223 tracks that test it) and Hallmark oxidative phosphorylation, no longer lead every gene's list; ties fall back to studies, conditions, direction agreement and padj. Each row gives the conditions and studies it recurs in, its enrichment over the base rate with the corpus count, the up/down split, the NES and padj of its strongest condition, a link to its pathway page and to the full pathway report; each condition shows how many pathways it contributed or that it has no pathway analysis. The rows come from a new per-track query-index family (`trackpaths/`, 229 files, built and verified by `scripts/build_query_index.mts`) copied from the pathway index's own rows, one small file per followed track; each row also carries the pathway's corpus counts (significant and tested tracks), so the rank needs no further request. Nothing downloads a pathway sibling or track bundle, and an index without the family keeps the reserved slot.
- Gene reports preserve the exact selected study cohort when opening bar comparisons. Shared analysis links restore contrasts, selected genes, chart scales, thresholds and study filters; malformed restrictions do not silently widen to all studies.
- Gene CSV and Excel downloads include study, contrast, units, retained processing/replication evidence, release identity and export settings. Excel adds a Metadata sheet; filenames distinguish datasets and contrasts. Scientific numeric precision is preserved.
- Direction and significance text use accessible text colors while plots retain the established fill palette.
- Build metadata records the source commit, working-tree fingerprint and immutable query/expression data builds. Release verification and the update watcher distinguish snapshots that share an app version.
- The macaque upstream record now cites the reviewed Lei et al. methods: STAR 2.5.3 and Macaca_fascicularis_5.0, with unspecified annotation/counting details stated explicitly.
- Original code is licensed under MIT and original contributions to derived outputs under CC BY 4.0, with separate third-party terms. Added software citation, local archive packaging and publication guidance.
- Application CI adds type checking, the full test suite, lint and production browser smoke checks. Biome excludes nested tool worktrees.
- **Dataset library as a record view.** A filter bar replaces the facet rail: a view menu of browse themes, a sort chip, one removable chip per active filter and an Add filter menu that keeps the per-value counts and replicate floors. The table is the default layout, with a sticky header, Study column and count footer, and Export CSV writes the visible studies (unmeasured counts left empty).
- **Study record page.** Selecting a study opens a page in place of the modal: a header with a previous/next stepper, Compare and Open in explorer; a fact strip; Overview and Verification tabs; and a Details panel. Escape, the breadcrumb and browser Back return to the list with its filters, scroll and focus. Nothing loads into the explorer until Open in explorer.
- **Volcano on the study record, on request.** Show volcano plot draws the default track at FDR < 0.05, matching the record's significant-gene count, with the top genes up and down beside it, a case-insensitive gene search that distinguishes tested-but-not-passing from not in the track, and a download of every passing gene. Nothing downloads until the reader asks; after that, stepping to the next study draws its volcano too.
- **Search-first home page.** The home page is the logo, one search box and two cards: Browse the dataset library and Survey baseline expression. The box switches between genes and pathways, suggests names as you type and opens the results page directly; its filter button opens the full search dialog, where Genes and Pathways tabs share the study filters and the box follows the side used last. `/` focuses the box from anywhere on the page. A small top nav (Library, Genes, Pathways, Survey, Methods) and the footer keep a route to every other tool. Suggestion lists download only once the box is focused.
- **Typography and palette.** Hanken Grotesk replaces Source Serif 4 and Source Sans 3 for text and headings, and Geist Mono replaces IBM Plex Mono for numbers and identifiers, all self-hosted with SIL OFL licenses and provenance; Source Sans 3 and IBM Plex Mono remain as fallbacks for missing glyphs. Interface neutrals move to a warm off-white family (page `#FAF8F5`, text `#27251E`), and muted and neutral result text meet WCAG AA on every surface. The brand guide and DESIGN.md record both changes; the logo is unchanged.
- The data gate Worker (`workers/data-gate`) is retired. Protection of `data.hypoexplorer.com` moves to Cloudflare edge cache and WAF rules, with a cache purge after each upload and a scheduled spend guard on R2 reads. `npm run typecheck` no longer needs Wrangler authentication.

## [0.15.0.0] - 2026-09-26

Every analysis result was recomputed under R 4.6.0 (September 25–26). This release also carries the changes merged to `main` after 0.14.3.0 (#52–#59), which still reported 0.14.3 in the version badge; they are listed with their dates.

### Added
- **Upstream processing in every study record (2026-09-25).** The study fact table, the prerendered study pages and `/methods` show the depositor's aligner, genome build and annotation, parsed from the repository records of the 160 source accessions into `geo_replication/config/upstream_processing.tsv`. HypoExplorer starts from the depositors' processed data and does not realign reads. The macaque atlas row (CNP0003785) still needs a hand reading of the source paper's methods.
- **A session and provenance record for every result table (2026-09-25).** Each bulk DE, SE and FGSEA table and each macaque population has its R `sessionInfo` and a provenance record of package versions, handling rules, design, samples and input and output SHA-256.
- **Search opens as a dialog (#53, 2026-09-18).** The home page's Search genes and Search pathways buttons, and empty `#/gene` / `#/pathway` links, open a large search dialog over the current page with the input focused. Close, Escape or a backdrop click returns to where the reader was; the full results page opens only on a non-empty submit.
- **Study filters on the explorer search pages (#52, 2026-09-17).** An All datasets card and 11 category cards with study counts replace the example chips and the six gene shortcuts. A Larger groups filter keeps studies with at least 5 samples per group in the default population and comparison (unknown counts excluded), and Pipeline QC / Experimental design / Author concordance "Passed" filters narrow the scope. The study picker gained Select all and Clear selection, Pathway Explorer lists only pathway-capable studies, filters persist per explorer, and a search requests data only for the selected studies.
- **Result previews (#52).** Hovering, focusing or tapping a fold change in gene results shows that study's bar chart for the exact comparison (group means ± SEM with samples); the same on an NES shows an approximate running enrichment-score plot built from the leading-edge genes. Each result row carries More information (the library record), Open → and a compare-set toggle.

### Changed
- **All DE, SE, CPM and pathway results were recomputed under R 4.6.0 (2026-09-25).** edgeR 4.10.1, limma 3.68.4, fgsea 1.38.0 and msigdbr 26.1.0 (MSigDB 2026.1.Hs) now produce all 202 bulk DE tables and the 60 macaque populations. The macaque atlas and 142 bulk tables had been made under R 4.4.1 with edgeR 4.2.2. Values and significance calls change: bulk FDR < 0.05 calls go from 129,674 to 129,326 and significant bulk pathways from 51,308 to 49,480; macaque FDR < 0.05 genes go from 763 to 613, with no significant gene changing direction, and significant macaque pathways from 2,113 to 2,399. Every difference is attributed to the environment or to the rules below in `data/quality/regeneration-r460-2026-09-25/README.md`.
- **One rule for duplicate symbols and fractional counts (2026-09-25).** Features that share a gene symbol are combined before testing (counts summed, log values averaged) instead of keeping the strongest row after testing, but only when they are distinct stable gene IDs annotated to one symbol or repeats of one label. Other collisions publish only the exact-label feature. Spreadsheet-damaged 1-Mar / 2-Mar labels, which can mean MARCHF1/2 or MTARC1/2, are shown only when a gene ID, gene name or chromosome column resolves them; this adds Mtarc1 or Mtarc2 rows to GSE148641, GSE167105 and GSE198437 and hides the labels in GSE143818 and GSE190389. Zero-padded month labels map to the right symbol (`Sep-01` → Septin1, not Septin01; 16 labels in GSE190389). Features without a symbol stay in the model, so normalization and the FDR correction see the whole library, but are not shown. Fractional count estimates are no longer rounded; this changes GSE235479, E-MTAB-6929, GSE229838, GSE282067 and GSE205313, which was rebuilt from its GEO Salmon files.
- **Count studies show CPM (TMM-normalized) (2026-09-25).** Bulk count studies displayed CPM on raw library sizes. They now display TMM-normalized CPM computed with the normalization factors of the study's own edgeR fit, as the macaque atlas already did. Sample values in charts and exports change accordingly. Studies analysed from a deposited normalized matrix keep that matrix's unit. The raw-library CPM is still computed for comparison but is not published.
- **GSE87544 is marked exploratory (2026-09-25).** Its design leaves 1 residual degree of freedom. edgeR 4.10 finds 1 gene at FDR < 0.05 where edgeR 4.2 found 224, with nearly identical fold changes, so its gene-level calls are not reliable. Read its effect sizes and pathway ranks instead.
- **Verification badges after the regeneration (2026-09-26).** Pipeline QC totals are unchanged (83 passed, 60 review, 18 not assessed). The macaque atlas now passes its normalization, model, matrix, library and output checks, refitted from committed pseudobulk counts, and stays at review overall. GSE205313 passes count conservation. Author concordance for GSE201408 (coverage) and GSE298648 (magnitude) moved from passed to review, because author genes that match only unmapped features are no longer published.
- **The Methodology and Statistics pages describe the analysis environment and the handling rules (2026-09-25).** The GO:BP worked example uses the regenerated sizes: under MSigDB 2026.1.Hs, GOBP_CELL_CELL_ADHESION is dropped in i25 and kept in i15.
- **Typography (#52).** Source Serif 4 for headings and Source Sans 3 for body text replace IBM Plex Sans across the app, the public pages and the tracker; IBM Plex Mono stays for numbers and identifiers. All fonts are self-hosted.
- **Home page (#52).** The Expression survey is the fourth main tool. Search buttons replace the inline search boxes and chips. More tools drops Compare populations, Compare datasets, Single-cell datasets, the GSE220533 diet comparison and the Planned block; Local datasets is renamed Explore Local Datasets; footer links are grouped under Explore / Analysis / Reference; the footer's Lei et al. credit was removed.
- **Results pages (#52).** Study filters sit in a collapsed section above results. Per-row GEO/DOI/PubMed links, citations, the verification link and the low-sample icon moved behind More information. Pathway results collapse by category and study, studies with more than three tracks show only significant tracks until expanded, track IDs link to that track's Pathway tab, and the NES axis is no longer capped at ±3.
- **Compare set and expression survey (#52).** The compare set drops its chip row: each sidebar study has a remove button, its comparison label, byte progress and a Details section. The expression survey is narrower, starts with an empty gene box (no Lepr default, chips or Marker panel), and reveals export and display controls only after a survey runs.
- **Layout at 900 px and below (#53).** The explorer's Cells list, the library filters and the compare-set study list move into button-opened dialogs; study details, verification and volcano settings fold into collapsible sections; pages scroll normally; wide tables and explorer tabs scroll horizontally within their own box. At 600 px and below, controls are at least 44 px and inputs use 16 px text so iOS Safari does not zoom on focus. Desktop windows 700 px tall or less scroll the explorer and keep at least 440 px for the chart.
- **The website changelog covers every release since 2026-08-19.** Entries for 0.7.2.0, 0.7.3.0 and everything from PR #37 to #53 were added after an audit against the git history, and two factual errors in existing entries were corrected.
- **The website changelog lists bug fixes and smaller improvements, not only features.** A second audit against every commit added about 60 fixes and changes to existing entries, new entries for 2026-04-19, 2026-08-27, 2026-08-31 and 2026-09-24, and the dataset library launch, the Developmental programming category, the GSE162744 and GSE314184 relabels and the edgeR standard-error correction, none of which the website had announced.

## [0.14.2.0] - 2026-09-15

### Added
- **An expression survey at `#/expression`**, reachable from **Expression survey** on the home page. It surveys per-sample expression in hypothalamic populations, isolated neurons and bulk tissue, across the NeuroSeq import and 31 curated existing sources. Its four sections are Gene survey, Population catalog, Tissue & bulk, and Sources & validation. Population identity groups related preparations for discovery: each source keeps its own measurement scale, RNA fraction, condition and sample values, and the view neither computes a cross-study mean nor treats expression as differential expression. TRAP/RiboTag, sorted total RNA, bulk tissue and single-cell pseudobulk stay distinct preparations even when all report CPM. Opening the view loads the source catalog alone; a survey or gene-example button starts the value requests.
- Library study cards carry result bars: the genes and pathways reaching FDR 0.05 on the default track, with their up and down split and the tested denominator, and a detail panel on hover or keyboard focus. A study measured at zero reads as none at that threshold rather than as unmeasured, and a study whose pathways were never computed says so instead of showing an empty bar.
- The library sorts by **Genes found (most first)**, and the Power filter offers replicate floors of n ≥ 3, 4, 6 and 10, each rung carrying its own count, in place of the single fixed floor. Studies whose replicate counts are unmeasured remain excluded while a floor is on.

### Changed
- Expression survey queries read a dedicated lossless gene index: one immutable source and sample manifest plus one gene shard, shared by every selected population and tissue, rather than a full track for each source. Repeating a gene needs no further requests in that session, and adding a source the manifest already covers downloads none of its track. For Igf1r across four whole-hypothalamus studies this is one manifest and one shard in place of four full tracks, and 62,429 against 4,948,561 local gzip-6 bytes, a 98.74% reduction in estimated compressed bytes. That figure excludes app code and HTTP overhead and is not a production latency measurement. The retained validation records 534,346 feature rows and 5,785,609 exact finite sample values with zero numerical difference against the full-track adapter.
- Bundle and index publication is incremental. The uploader compares a fresh R2 inventory against the stored-byte MD5, size and HTTP metadata, skips unchanged objects, reuses verified compressed bytes locally, and verifies every required payload at R2 before writing either mutable pointer. A no-op run performs metadata reads and no writes. A remote ETag that is not an MD5 cannot authorize a skip, and a failed upload withholds the pointers so that a rerun skips only what already succeeded.
- The data gate serves `/query/tracks.js` and `/query/expression-manifest.js` with 300-second edge and browser lifetimes on one shared, policy-versioned cache entry, which isolates the previous four-hour entries and merges client version variants. The service worker holds mutable pointers to the same 300 seconds. A failed pointer lookup is never retained.

## [0.8.0.0] - 2026-08-27

### Added
- **A Circadian tab: rhythm detection over a dataset's time course.** Three tests — JTK_CYCLE (non-parametric rank correlation against cosine references over a period x phase grid, Bonferroni-corrected for that grid), COSINOR (least-squares cosine fit, F-tested against a flat mean), and Lomb-Scargle (least-squares periodogram, Horne & Baliunas independent-frequency count) — all run **in the browser** over the whole transcriptome, so the method, the period (24 h pinned or a 20-28 h scan), the arm, and the multiple-testing correction are user choices rather than a generator's.
